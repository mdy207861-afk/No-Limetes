# NO LIMITES — بوت الحضور والانصراف

بوت مستقل يعمل بالأزرار فقط، ولا يحتاج أوامر Slash للأعضاء.

## المميزات
- 🟢 تسجيل دخول و 🔴 تسجيل خروج.
- 🏆 TOP 10 خاص بالشخص الذي ضغط الزر، ويتحدث كل 5 ثوانٍ لمدة دقيقتين.
- 🌐 اختيار اللغة لكل عضو بشكل مستقل: العربية أو English.
- سجل دخول وخروج في روم مخصص مع منشن العضو.
- حفظ البيانات في `data/store.json` حتى بعد إعادة تشغيل البوت.
- يحسب المدة من طوابع الوقت الفعلية، وليس من عداد يزيد كل 5 ثوانٍ.
- يعتمد توقيت UTC داخلياً ويعرض الوقت بتوقيت السعودية `Asia/Riyadh`.

> ملاحظة: أزرار اللوحة مشتركة بين الجميع، لذلك عناوين الأزرار ثنائية اللغة، أما ردود البوت ولوحة TOP 10 فتظهر بلغة العضو المختارة.

---

## 1) إنشاء تطبيق البوت
1. افتح Discord Developer Portal: https://discord.com/developers/applications
2. اضغط **New Application** وسمّه `NO LIMITES`.
3. افتح تبويب **Bot** ثم **Add Bot**.
4. من صفحة Bot اضغط **Reset Token** أو **View Token** وانسخ التوكن. لا ترسله لأحد ولا تصوره.
5. افتح **OAuth2 > General** وانسخ **Application ID**. هذا هو `CLIENT_ID`.

لا تحتاج تفعيل Message Content Intent أو Server Members Intent؛ البوت يعتمد على الأزرار فقط.

## 2) دعوة البوت إلى السيرفر
من **OAuth2 > URL Generator**:
- Scopes: اختر `bot`.
- Bot Permissions:
  - View Channels
  - Send Messages
  - Embed Links
  - Read Message History

انسخ الرابط الذي يظهر أسفل الصفحة وافتحه، ثم اختر سيرفر NO LIMITES وأكمل التفويض.

## 3) تجهيز الرومات
أنشئ رومين نصيين:
- روم لوحة الحضور، مثال: `attendance`
- روم السجلات، مثال: `attendance-logs`

انسخ ID السيرفر والرومين:
1. في Discord افتح User Settings > Advanced.
2. فعّل Developer Mode.
3. اضغط بزر الفأرة الأيمن على السيرفر ثم Copy Server ID.
4. اضغط بزر الفأرة الأيمن على كل روم ثم Copy Channel ID.

تأكد أن البوت يستطيع مشاهدة الرومين وإرسال الرسائل والتضمينات فيهما.

## 4) تشغيل المشروع على Windows
1. ثبّت Node.js إصدار 20 أو أحدث من: https://nodejs.org
2. فك ضغط ملف المشروع في مجلد واضح، مثل `C:\\NO-LIMITES-BOT`.
3. افتح المجلد.
4. انسخ ملف `.env.example` وسمّ النسخة `.env` (انتبه لا يصير اسمه `.env.txt`).
5. افتح `.env` بالمفكرة واملأ القيم:

```env
DISCORD_TOKEN=ضع_توكن_البوت
CLIENT_ID=ضع_Application_ID
GUILD_ID=ضع_Server_ID
PANEL_CHANNEL_ID=ضع_ID_روم_لوحة_الحضور
LOG_CHANNEL_ID=ضع_ID_روم_السجلات
```

6. افتح Terminal داخل مجلد المشروع. أسهل طريقة: من شريط عنوان المجلد اكتب `cmd` واضغط Enter.
7. نفّذ:

```bash
npm install
```

8. بعد انتهاء التثبيت شغّل:

```bash
npm start
```

إذا ظهر `Logged in as ...` فالبوت اتصل. سيُرسل لوحة الحضور تلقائياً في روم اللوحة. إذا أعدت تشغيله، سيحاول تحديث اللوحة نفسها بدل إنشاء لوحة جديدة.

## 5) طريقة الاستخدام
- 🟢 تسجيل دخول: يبدأ جلسة جديدة ويحفظ وقتها.
- 🔴 تسجيل خروج: ينهي الجلسة، يحسب المدة بدقة، ويضيفها إلى مجموع العضو.
- 🏆 TOP 10: يعرض أعلى عشرة أعضاء، ويتحدث كل 5 ثوانٍ لمدة دقيقتين.
- 🌐: يفتح زري 🇸🇦 العربية و 🇺🇸 English. الاختيار خاص بالعضو.

## 6) البيانات والدقة
- البيانات محفوظة في `data/store.json`. لا تحذف هذا الملف.
- إذا توقف البوت والعضو ما زال مسجلاً، تبقى جلسة الدخول محفوظة ويستمر حسابها من وقت البداية عند عودة البوت.
- لا يوجد مؤقت يزيد الوقت كل خمس ثوانٍ؛ المدة تحسب بطرح وقت الدخول من وقت الخروج، وهذا أدق.
- أوقات السجلات معروضة بتوقيت السعودية.
- خذ نسخة احتياطية من مجلد `data` عند الحاجة.

## حل المشاكل
- `Invalid Token`: تأكد من نسخ Bot Token الصحيح دون مسافات.
- `Missing ...`: تأكد من تعبئة كل القيم في `.env` وأن الملف اسمه `.env` وليس `.env.txt`.
- `Missing Access` أو `Missing Permissions`: أعطِ البوت صلاحيات مشاهدة وإرسال الرسائل وEmbed Links في الرومين.
- لم تظهر اللوحة: تأكد أن `PANEL_CHANNEL_ID` هو ID روم نصي صحيح.
- لا تشارك التوكن مع أي شخص. إذا انكشف، أعد تعيينه من Developer Portal فوراً.

هذا الإصدار مستقل، حتى لا يغيّر أو يعطّل بوتاً آخر موجوداً عندك.
